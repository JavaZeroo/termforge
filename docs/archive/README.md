## 归档内容

- `milestones/`：早期 M0 规格，以及已交付的主区本地会话、DPI/zoom 切片规格。
- `reviews/`：10 份历史实现/取证审查，保留原始基点、发现和修复说明。
- `validation/`：第二至第四批的验证叙述。原始结果仍在原 experiments/benchmarks 目录，未改写测量数据。
- 研究报告与 ADR 仍留在各自目录，保留事实和决策；过时状态有历史范围说明。

旧 STATUS-AND-BACKLOG 的重复过程表由当前矩阵和本迁移表替代；原文可在[整理前版本](https://github.com/JavaZeroo/termforge/blob/2dc8d6de4a607b39b93d3a2c07adb191209120ae/docs/STATUS-AND-BACKLOG.md)查阅。没有删除原始证据，也不把历史验收升级成完整产品声明。
