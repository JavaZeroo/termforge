# 主连接区本地会话切片

> 历史归档：保留当时的范围、结论和限制，不作为当前待办。当前能力见[矩阵](../../FEATURES.md)，后续任务见[路标](../../PLAN.md)。

用户要求继续完善 UI。固定起点为 `99fbecba2053fefed37bc5d50194f725413f6390`；依据为[第二轮 UI 调查](../../research/windterm-ui-typography-2026-10-23.md)。本切片把已经测得的主区域用于真实本地会话，不将资源或反编译实现复制进客户端。

## 行为与验收

- 主区和底部 Shell 区分别保留选中的标签，可同时显示两个真实 cmd；同区其他标签在隐藏时继续消费输出。所有区域合计最多八个会话。
- `Ctrl+T` 保留新建底部 shell；`Ctrl+Shift+T`、主区加号和 Session 菜单新建主区本地会话。工具栏提供已经实现的新建、关闭、重命名动作及只读本地目标说明。
- 点击终端或标签改变操作焦点；关闭、重命名和切换快捷键针对当前区域。主区与底部独立保留状态。后台会话退出不能把键盘焦点从另一终端或重命名编辑器移走；不能向被焦点模式隐藏的终端发送输入。
- 主区最后一个标签关闭后恢复空状态，可以重新新建。关闭主窗口回收两个区域的全部自有进程。
- 96 逻辑单位下，默认 1360×860 主标签容器为 `[227,33,906,26]`，工具栏 `[227,59,906,34]`，主终端外区域 `[227,93,906,453]`；2048×1120 对应 `[342,33,1364,26]`、`[342,59,1364,34]`、`[342,93,1364,626]`。空标签容器高 19。测试分别验证布局矩形与实际子窗口位置/尺寸。
- UI 使用从独立公开上游取得且许可明确的 Roboto Mono，随构建复制并在进程内私有加载；核实实际选中的字体名称。终端绘制网格与字体保留既有行为，后续单独验证。
- 自动场景运行于自有非输入桌面，使用真实 cmd 验证两区域输出隔离、切换、重命名、后台退出、缩放后子进程尺寸、空状态恢复及关闭回收。既有 UI/布局恢复与 shell 回归须继续通过。

## 边界

本切片仅实现本地会话，不增加 SSH、会话恢复、终端历史浏览或完整动作兼容性。标签标题测量、终端字体 fallback、真实跨屏 DPI 与像素等价仍未验收；终端仍遵循物理行 resize，缩窄会截断内容。主区域外框的几何对齐不等于内部文本网格、性能或完整 WindTerm 行为一致。
