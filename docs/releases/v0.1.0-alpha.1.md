TermForge 首个 Windows x64 Alpha 预发布包，交付 **R1 基础文字交互原型**。适合体验和反馈；R2 可靠本地终端与日常开发版仍在后续计划中。

## 下载与运行

下载 `TermForge-v0.1.0-alpha.1-windows-x64.zip`，完整解压后双击 `termforge_shell.exe`。保留同目录 `shell_clipboard_reader.exe` 和 `assets/fonts/`；运行不依赖 Python、CMake 或 Visual C++ Redistributable，采用静态 MSVC 运行库 `/MT`。发布页另附 `SHA256SUMS.txt`，包内 `build-info.json` 记录源码与文件身份。

这是未签名的免安装 ZIP，Windows 可能显示未知发布者。布局配置仍写入 `%LOCALAPPDATA%\TermForge\workspace-v1.layout`，并非全数据便携模式。

## 已有能力

- 真实 Windows cmd/ConPTY，两区域合计最多 8 个本地会话，新建、切换、关闭和重命名。
- 最多 100 行有界历史、选择与系统复制、有界粘贴及多行确认、字面量查找。
- 每会话文字缩放、分隔线和部分布局保存；固定 Microsoft 拼音的限定组合、提交与取消场景。
- R1 的同次八会话 Copy→Paste→IME 流程、后台有限负载、取消/关闭及资源回收已有独立验收记录。

常用快捷键：`Ctrl+Shift+T` 新建主区会话，`Ctrl+T` 新建底部会话，`Ctrl+Shift+C/V` 复制/粘贴，`Ctrl+Shift+F` 查找，`Ctrl++/-` 缩放，`Ctrl+0` 重置，`F11` 扩大底部 Shell。

## 平台与已知限制

包面向 Windows x64，已验范围限 Windows 11 本机和 Windows Server 2025 CI。Windows 10 未验收；Windows Server 2022 的已知 ConPTY 资源问题尚未解决。Linux 只有核心 CI，本次不提供 Linux/macOS 客户端。

尚无 SSH/SFTP、常用 TUI/备用屏、逻辑行 reflow、完整配置与会话持久化。缩窄按物理行裁剪，增宽不会恢复被截去的文字。Explorer/Filer/Outline 仍为空面板，UI 也未全面等价；其他输入法、真实跨屏 DPI、长期稳定和 WindTerm 性能等价均未验收。

源码和文档采用 MIT，随附 Roboto Mono 字体保留 OFL 许可。实现不依赖 WindTerm 二进制或专有资源，与 WindTerm 或 KingToolbox 无关联。

完整能力边界见[功能矩阵](https://github.com/JavaZeroo/termforge/blob/v0.1.0-alpha.1/docs/FEATURES.md)，操作见[本地 shell 说明](https://github.com/JavaZeroo/termforge/blob/v0.1.0-alpha.1/experiments/shell/README.md)。请通过 [Issues](https://github.com/JavaZeroo/termforge/issues) 反馈版本、Windows 版本和复现步骤。
