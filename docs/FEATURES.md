# 功能与已知差异矩阵

所有客户端功能当前均为 **未实现**。优先级是计划，不是可用性声明。

研究代码已有[最小状态回放 v0.1](../experiments/core/README.md)：ASCII、基础光标/擦除和有界历史可自动测试，并已接入自有管道。这是有限子集实验，不表示下面的完整 VT、Unicode 或客户端能力已实现。

| 能力 | 阶段 | 主要验证点 |
|---|---|---|
| VT 解析、屏幕状态、Unicode、输入 | M1/M2 | 拆包、宽字符、组合字符、备用屏幕、resize |
| 历史存储、滚动、搜索 | M1/M2 基础，M4 扩展 | 内存/延迟、搜索正确性、长期增长 |
| PowerShell/WSL 本地终端 | M1 原型，M3 产品化 | PTY 生命周期、中文输入、退出清理 |
| SSH 认证、跳板/代理 | M3 | 密钥、agent、交互认证、取消/超时、链路故障 |
| 主机指纹、凭据管理 | M3 | 初次信任、密钥变化、系统安全存储 |
| SFTP 与队列 | M3 | 完整性、取消、重试、覆盖、错误恢复 |
| 会话分组/搜索、标签/分屏 | M3 | 状态一致性、布局恢复、多会话公平性 |
| 配置、日志、备份、安装包 | M3 | 迁移、资源回收、干净环境构建 |
| 高级高亮、折叠、补全 | M4 | 语义正确性、后台预算、性能退化 |
| SSH 转发、远程编辑、批量输入 | M3/M4 细化 | 转发生命周期、上传冲突、目标可见性 |
| Telnet、串口、X/Y/Zmodem、X11 | M4 | 独立协议和平台验证 |
| tmux 深度整合 | M4 | 区别于在普通终端中运行 tmux |
| macOS/Linux 产品支持 | 阶段评估 | 平台构建、字体/输入/PTY 行为验证 |

WindTerm 是性能与体验参照，不承诺沿用其私有格式。会话迁移另设规格；未知加密凭据要求重新输入。
