# UI-B 拖动、重命名与布局恢复审查

日期：2026-10-23。固定起点 `905c0fc81a63065e24475a70c7220c9ccebb1d7a`；审查对象为该基点后的工作区差异及四个新增头文件/测试文件。需求来自 [UI-B](../research/windterm-ui-2026-10-23.md) 与用户批准的下一批 UI 工作；两名独立审查者只读检查。

## Standards

初审发现 1 项 P2 交互正确性问题：Sessions 绘制只显示完整行，但命中区域允许点击被隐藏的末行。拖动新增了触发这个不一致的常见路径。

已修正点击条件，使整行可见边界与绘制一致。真实两会话场景通过鼠标消息压缩上部和右侧面板，点击未绘制行所在的空白处，确认活动会话不改变。小窗口下分隔线的 clamp 上下界同时保持有效。复审无剩余发现；没有新增来源边界违规或需要单列的代码异味。

## Spec

初审发现 1 项 P2 焦点问题：任何后台会话退出都会将焦点移回活动终端，导致正在进行的重命名提前提交，后续文字进入终端。这不满足 UI-B 的动作上下文与焦点要求。

已修正为保留仍存在的编辑器及其焦点。回归在编辑第二个标签时让第一个隐藏 shell 实际执行 `exit`，确认活动身份未变、编辑未提交；向当前焦点发送字符，检查字符仍留在编辑器，再取消编辑。复审无剩余发现；没有新增范围扩张。

## 实现与证据边界

- 五条 splitter 可拖动，比例有界，Esc/丢失 capture 回滚；焦点模式不覆盖普通布局比例。
- F2/中键/菜单打开独立 EDIT 控件；支持 Unicode，Enter/失焦提交，Esc 取消，空白/控制字符/不完整 UTF-16 拒绝，使用稳定标签 ID。标题仅用于当前进程。
- 独立 `LayoutState` 模块保存五个比例与两个显隐状态。读取有界且严格，损坏文件整体回退默认；独占临时文件与同目录原子替换，保存失败保留旧目标并显示状态。未承诺断电持久性。
- WindTerm 的资源声明和 `QSplitter::saveState/restoreState` 静态入口只提供规格线索，不证明 ShellPane 的完整交互、持久化格式或保存时机。当前行为规则由 TermForge 独立设计。
- 测试使用专属非输入 desktop、Job 和配置目录，无需用户操作；正常程序不录制或上传会话。合成截图仅在本地核验，不作为实际呈现完成或像素等价证据。未上传含构建路径的图片、stdout/stderr 或 WindTerm 私有材料。
