# UI-A 首个工作区切片：审查与验证

基点 `c218836ed52bea02e386de420b09ef07600db3ac`。用户要求继续 UI 对齐；本批复用已取证的空主区域 + 底部 ShellPane 状态，先交付可运行工作区。UI-A 的主连接标签状态、字体/DPI，以及 UI-B 的拖动/重命名/持久化仍待完成。实现为原创 Win32 外壳，未复制 WindTerm 资源或实现。

## Standards

独立代理审查 AGENTS/CONTRIBUTING/PROVENANCE、生命周期、共享窗口类、异步关闭、隐藏会话和绘制边界：无可操作发现。窗口、解析和传输所有权保持分离，关闭后才回收标签对象。

## Spec

独立代理核对 1360×860 和 2048×1120 的初始几何、动作处理、自动验收及范围声明：无可操作发现。布局参数对应已有运行时证据，空面板和字体差异明确披露。审查指出键盘加速键、Sessions 列表点击和后台新输出未被原场景覆盖；随后补测后两项。键盘加速键路径仍未做物理键盘验收，自动场景走窗口命令和鼠标消息。

## 验证

- Release 构建通过；本机全套 12 个 CTest suite 通过，76.83 秒，包括既有 C5 裁剪窗口重绘回归。
- 随后对增强场景重新构建并运行 UI 专项（2 次）通过：两个真实 cmd 的独立状态、隐藏标签新输出、Sessions/标签点击、焦点模式往返、侧栏显隐、窗口放大、关闭最后标签后新建第三会话，以及主窗口退出回收。
- 子进程独立查询实际 console 为 113×27、113×7、170×11；三个会话最终回收，外部 Job active=0、owned desktop 消失。
- 合成 DIB 1360×860 已目视检查，并断言左右分隔线、上下分隔线、Shell 标题、活动标签下划线和状态栏的独立参考坐标/颜色。
- 画面由相同 UI 绘制函数和终端保留 DIB 合成，非用户桌面截图；不是实际呈现端点，也不代表完整像素等价。

操作与剩余限制见[本地 shell 工作区](../../experiments/shell/README.md)。不声明完整 WindTerm UI 或性能等价。
