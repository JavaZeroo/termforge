# ADR-0011　备用屏 RIS 后保留可见的新输出

2026-11-26，项目负责人确认。适用范围为 #334 的备用屏 RIS 正文与历史归属。

固定 WindTerm 2.7.0 在备用屏复位后，可从主屏回看原历史和部分备用屏旧文字。此时继续向主屏第 8 行第 9 列写入 `POST`，该位置未出现输入的字形。逐阶段滚动与只在最终返回后滚动的两个独立会话得到相同结果。[原版记录](../research/r334-ris-content.md)

用户确认：

> 保留可见的新输出，复刻已确认的旧文字回看行为，并把新输出的差异记入 #334（推荐）

TermForge 在复位后的主屏保留旧正文，按实测范围把备用屏旧行纳入有界历史。在当前主屏写入的文字立即显示，经过显式返回和再切换后仍可读。主屏与备用屏后续各自接收的新文字留在对应帧。正式验证分别读取子进程原生网格、Qt 屏幕模型和主屏历史的实际滚动页面。[执行记录](https://github.com/JavaZeroo/termforge/issues/334)
