# 有界显示投影跨步骤续接

`ProjectionJob` 解决了静止源上长软行无法跨越单次预算的问题：500 个单列源片段在放大到 500 列时，分 **200 / 200 / 100** 步生成完整一行。每步上限仍为 200，未完成的半行及页面留在任务内部，不交给显示消费者。这里新增的是工程能力，未增加原版行为结论，也未切换默认 Qt 路径。

## 实际基线与实现

旧 `HistoryViewport::project` 在源码 `3d4c8c2` 上实际运行：两个独立请求各读 200 个片段、都返回零显示行和起点 `(0,0)`；201 片段请求被资源上限拒绝。诊断 exit 0 表示成功复现停滞，不是修复通过。旧诊断 EXE、日志和固定 Git blob 于运行后归档，身份 SHA256 `482b460b1ad475d555e6758ebc6f6e606e5842ef78434e45172800555dc73459`；没有运行前 manifest。新 API 没有先行 RED，不将缺 API 或临时适配代码伪装为真实失败。

新任务绑定 Screen owner、buffer epoch、结构 revision、独立内容 revision 和布局请求代次。内容被原地覆盖、同 ID/version 导入、尺寸改变或新请求到来时，未发布内容失效；尺寸不变保持任务。准备异常取消该任务，旧显示页不被半套替换。隐藏帧 resize 准备失败保持两帧和 revision。成功页携带精确源范围，下一页从源锚点继续，不扫描已过的历史前缀。

源锚点允许作为不同宽度下的新局部显示起点；它不是全局显示行号，也不证明与整个文档从头排版后的边界对齐。未缓存的任意显示位置查找仍待实现。
