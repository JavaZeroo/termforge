## Qt 实际执行的行为

保留原单会话检查：向真实 cmd 输入 `set /a 731+19`，独立字面期望 **750**，结果三格有新增正文墨迹；自然退出 **37**、启动失败可见错误和人工关闭回收均执行。

多标签检查实际点击 `+`、标签及关闭按钮，核对当前输入焦点。两个真实 cmd 分别执行 `731+19` 和 `401+26`，独立期望 **750 / 427**，命令与结果不串入另一个会话；父窗口图像中对应正文格有新增墨迹。关闭一个标签后，存活页继续得到 **778**，自然退出 **41** 后完成容器。另一个场景中，启动失败标签显示错误且不妨碍存活页得到 **147**；父窗口关闭回收全部会话，单独失败启动页在用户关闭前保留可见错误。

应用退出另使用 smoke 内真实 `QApplication::exec()`，沿产品相同的 `SessionTabs`、`quitOnLastWindowClosed(false)` 及 `on_all_exited → app.exit` 策略覆盖四条边界：

1. 关闭含两个活动 cmd 的父窗口。
2. 关闭最后一个活动标签。
3. 关闭单独的启动失败页。
4. 关闭已自然结束的标签。

在统一完成回调、`aboutToQuit` 和 `exec` 返回三个检查点，核对所有会话模型已结束、回收可验证且各自 Job active=0。已移除页若已被延迟删除，采用其仍存活时取得的回收记录；不使用 `exec` 返回后的模型析构或仅外层 Job=0 来替代退出前证明。这是与产品相同入口合同的应用窗口测试，**不是另行黑盒操纵产品 EXE 的完整交互验收**。

人工关闭成功返回 0；源码对“模型已结束但回收不可验证”返回 1，不等待一个不会再变化的标志。失败状态分支由源码及最终审查核对，未声称另做应用级回收失败注入。成功启动的最后会话自然结束沿原型入口的退出路径和状态；启动失败页由用户关闭。外层期限仍为 **25 秒**，CTest 期限仍为 **35 秒**。
