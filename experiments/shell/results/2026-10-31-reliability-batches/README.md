# 三类持续未复现项的量化批次（#144 / #145 / #160）

同一 artifact 集（run 41198898623，hosted Windows 2025）里，这三个历史上偶发的问题都没有复现。本记录把三批数据放在一起，便于判断证据强度。

| issue | 批次 | 关键计数 | 结论 |
|---|---|---|---|
| #160 desktop 沉降 | 425 个 `sample.json` | 全部 `[{elapsed_ms:0, gone:true}]`；缺失 5 条均为刻意构造的 `desktop-failure` 负例 | 关闭后首次检查即消失，无退避 |
| #145 resize 旧尺寸回复 | 10 个配置 / **1500 轮** | `stale_buffer=0`、`stale_window=0`、`buffer_window_disagreement=0` | 无陈旧回复样本 |
| #144 Node 10 秒停顿 | 60 顺序 + 20 并发 | 中位 0.062 s、最大 1.969 s（冷启动首例）、超时 0 | 宿主正常时远低于期限 |

## 为什么放在一起

三项的共同点是：复现依赖宿主侧偶发状态，而不是固定输入可触发的确定性缺陷。三批数据都指向"当前批次未复现"，但都没有反例，因此三项都保持开放。

## 限制

- 三批来自同一 run 的不同 artifact，不拼成一次"全绿"；
- 各自的原始失败记录仍然保留，未被新批次覆盖；
- `resize_to_reply_us` 等计时是探针自身测量，不构成性能声明。
