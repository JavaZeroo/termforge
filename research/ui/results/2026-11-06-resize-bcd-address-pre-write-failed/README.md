# WindTerm BCD 写前取证：授权一次尝试的失败保留

本记录保留 `#320` 第 6 节最小取证的**一次已授权运行尝试**及其精确阻塞。目标是固定 WindTerm `80×24→60×12`、B/C/D 与后续 `CUP 12;1+RRESIZED`，并在 resize 后、写入前记录正文。实际运行在初始几何检查即失败，**没有进入正文阶段、没有写前/写后字面结果、没有严格公开导出**；同一计划不重放。

## 发生了什么

- 探针/控制器按计划请求初始窗口 `1228×869`，期望实测网格 `80×24`；实际通过 NAWS 得到 **80×25**，控制器在 `fixed initial grid differs` 处停止，未发送初始 B/C/D 正文，未产生任何阶段记录。
- 因此没有可发布的写前正文、CUP 写后端点或 DSR 结果；严格导出器未运行（无合法观测可导出）。
- 未修改旧录制、旧报告或旧六阶段失败；**没有重放同一计划**。`.attempted` 保留。
- 运行期间为容纳更高窗口，临时把固定 VM 显示分辨率从 `1024×768` 调到 `1600×1200`，随后已恢复为 `1024×768`。该环境变更没有被冒充为原版固定环境；实际窗口矩形也因失败发生在几何检查之前而**未记录**。
- 计划/运行源的逐文件哈希与计划冻结值一致；失败只发生在目标网格预测，不是来源身份失败。

## 精确阻塞与解除条件

失败证明 `1228×869` 不能得到目标 `80×24`（实际 `80×25`），但该单次失败不足以反推一个可靠的替代窗口尺寸；不同高度的既有样本是非线性的，不能凭猜测重试。因此需要：

1. 一个**新的**冻结计划与新的单次授权（不能重跑 `7718a4b8…`）；先校准窗口高度到实测 `80×24`，或由调度者明确授权一次独立的几何校准；或
2. 若不能提供新授权/校准，则保留本阻塞，不用现有样本拼成 80×24 结论。

以上都不会自动改变 A/B/C 路线选择或旧六阶段断言；原版私有 raw 仍留在本地。
